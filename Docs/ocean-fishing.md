# Ocean Fishing

Everything here was derived from the game's own tables and verified against the
game's own Sailing Schedule window on 16 August 2026. None of it needs a web
request, a community spreadsheet, or a number maintained by hand.

## Where the data lives

`IKD` is Square's internal code for Ocean Fishing. The sheets:

| Sheet | Rows | Holds |
|---|---|---|
| `IKDRoute` | 22 | The routes. Row 0 is empty. |
| `IKDRouteTable` | 144 | The rotation — one row per voyage slot. |
| `IKDSpot` | 14 | The stops, via `SpotMain`/`SpotSub`/`PlaceName`. |
| `IKDTimeDefine` | 4 | Time-of-day values, `TimeOfDay` 0–3. |

`IKDRoute` carries `Name`, `Spot` (a collection of stops), `Time` (a collection
of time-of-day per stop), `Image`, and `Instance` (the duty row).

## The two boats

Routes group in threes — one per starting time of day — and split by boat:

| Routes | Boat | Destinations |
|---|---|---|
| 1–12 | Indigo (Limsa Lominsa) | Northern Strait of Merlthor, Rhotano Sea, Bloodbrine Sea, Rothlyt Sound |
| 13–21 | Ruby (Kugane) | One River, Ruby Price, Thavnairian Coast |

`IKDRouteTable` has two route columns: `Route` is the Indigo voyage for that
slot, and the column Lumina currently calls `Unknown0` is the Ruby one. Both
boats sail the same timetable to different destinations.

## Unlock gating

`IKDRoute`'s third unnamed column — `Unknown2` as Lumina currently calls it — is
the quest id a route requires. Zero means none.

| Routes | `Unknown2` | Requires |
|---|---|---|
| 1–12 (Indigo) | 0 | nothing beyond the feature unlock |
| 13–18 (One River, Ruby Price) | 68089 | Stormblood, the 4.0 finale |
| 19–21 (Thavnairian Coast) | 70000 | Endwalker, the 6.0 finale |

The activity itself is unlocked by **All the Fish in the Sea** (id 69379, level
1, patch 5.2), which is not per-route — routes 1–12 carry 0 — so it gates the
tab rather than any individual voyage.

So availability needs no table of our own:

```csharp
bool available = route.Unknown2 == 0 || QuestManager.IsQuestComplete(route.Unknown2);
```

which is the same shape as the expansion gating already in `TocService`.

## The rotation

All 144 rows are generated by a single twelve-element sequence, shifted one
place per day. Verified across every row:

```
S = [7, 10, 1, 4, 8, 11, 2, 5, 9, 12, 3, 6]          Indigo
T = [19, 13, 19, 16, 20, 14, 20, 17, 21, 15, 21, 18]  Ruby

slot N = 12 * day + i
    Indigo route = S[(day + i) mod 12]
    Ruby route   = T[(day + i) mod 12]
```

Twelve shifts returns the sequence to its start, which is why the table is
exactly 144 rows: twelve voyages a day for twelve days, one voyage every two
hours.

`T` contains 19, 20 and 21 twice each — nine Ruby routes across twelve slots —
which is why Thavnairian Coast falls on every other Ruby voyage. That
alternation is documented on the wiki independently, and the game's schedule
window shows it.

## The anchor

One number is not in the sheets: which real time corresponds to slot 0.

Verified anchor: **2026-08-16 22:00 EDT is slot 17.**

Established by matching 16 consecutive voyages of both boats against the game's
Sailing Schedule window. Three candidate slots (17, 65, 113) reproduce every
observed destination; they are 48 apart and differ only in which of the three
same-destination route ids is labelled, so no destination prediction can
distinguish them. Resolving that needs `IKDRoute.Time`'s values matched against
the schedule window's time-frame icons — see Open questions.

**Prefer reading the current slot from the client if it is exposed at all.** The
game computes that list already. An anchor shipped as a constant is one
hand-maintained number, and this codebase has been bitten by that category
before.

## Why not a website

The plan began as "base it on ffxiv.oceanfishing.boats and pillowfication's
repo". Both were dropped, for a reason worth recording:

- That repo's last real commit is 10 September 2023. Patch 7.5 added
  Thavnairian Coast on 28 April 2026. The site therefore shows Ruby voyages
  with no Thavnair at all — it is two patches stale, and its maintainer moved
  on.
- The game's tables gained Thavnair the day the patch landed.

During this work the site was briefly trusted over the sheets and produced a
wrong conclusion, which the game's own schedule window then overturned. The
site remains useful as an oracle for content older than 2023 — it was how the
Indigo anchor was found — and useless for anything newer.

This is the same argument that justified rebuilding v3: generated from the game
beats maintained by hand, and beats maintained by someone else even more.

## Open questions

1. **Is the current slot readable from the client?** If so there is no anchor
   constant at all. The Sailing Schedule addon renders 16 voyages, so something
   knows. Probe target.
2. **Which route id is day, sunset and night?** `IKDRoute.Time` is a collection;
   the probe printed its type rather than its values. Reconciling it with the
   schedule window's time-frame icons resolves both this and the three-way
   anchor ambiguity.
3. **What are the objectives per voyage?** The schedule window shows target
   fish; `IKDContentBonus` and `IKDFishParam` are unexamined.

## What a first version should do

The game already has this window. The only thing wrong with it is that it is
only reachable at the ferry dock. So: the same information, openable anywhere,
and nothing more.

- Next N voyages for both boats, in local time
- Destination, and the three stops in order
- Time of day per stop
- No automation, no queueing, no notifications — the plugin does not interrupt
  play and does not act on the player's behalf

Objectives and fish are a later question, and want the sheets in point 3
understood first.
