# 4.0.0.16 Production Sheet

One card per feature, worked top to bottom. A card is not done until every box
is ticked, and **"Tested in game" cannot be ticked by a successful build** —
that has been wrong three times now (title bar buttons, stale totals, the
companion window's height).

Release-day steps are at the bottom and are the same every time; they live in
detail in [releasing.md](releasing.md).

## The claim 4.0 has to earn

something derived. If a card cannot be described that way, it belongs in a 3.x

[ocean-fishing.md](ocean-fishing.md) for what the standard looks like in

### The gating test character

Gating is easy to write and impossible to test on a main, because a main has
done everything. Make one instead: a new character to level 10, unlock Fisher,
run *All the Fish in the Sea*. That gives Indigo unlocked and Ruby locked, and
it stays that way permanently — a fixture rather than a window that closes as
you play.

Worth keeping beyond this feature. Every progression-gated thing in the plugin
— expansion gating, spoiler mode, free trial detection, MSQ patch position —
is otherwise only testable against whatever a main happens to have finished,
which is why the allied society "maxed" row went out untested for six days
waiting on a second character to be in the right state.
