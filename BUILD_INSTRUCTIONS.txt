- Edit the <Version> element. Example:

  - Keep the final API digit consistent with Dalamud API level (transcript used `.15`).
  - Commit and push:

    git commit -m "release: bump version to 3.7.7.15"

b) Tag the release (tag name must start with `v`)

7) Troubleshooting tips
- If repo.json prints the wrong version, ensure bin/ and other artifacts are not stale. Rebuild Release with --no-incremental and re-run the builder script.
- If release assets do not appear after a successful Actions run, ensure the workflow attaches latest.zip on success; check the workflow logs for upload steps and errors.
- If Git refuses to push a recreated tag, delete remote tag and re-push:
  git push origin :refs/tags/v3.7.7.15   # delete remote tag
  git tag -d v3.7.7.15                   # delete local tag
  git tag v3.7.7.15
  git push origin v3.7.7.15
