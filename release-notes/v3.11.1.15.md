## Tales of Milestones

- **Fix:** the plugin unloads cleanly again. Since 3.11.0.15, every unload or update showed "unload error" in the plugin installer, and a game restart was necessary to load the plugin again.
- **Help text.** The Help tab now says where the news comes from: a public file on GitHub, built from the Lodestone news that lodestonenews.com collects. The request sends no character or account data.
- **Third-party notices.** The download now includes THIRD-PARTY-NOTICES.txt, with the licences of KamiToolKit and the Microsoft libraries that the plugin uses.
