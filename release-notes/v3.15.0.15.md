## Tales of Milestones

- **Smaller export (format 3).** Every id list in the export now writes a run of three or more consecutive ids as a pair, for example `[1700,1708]` for 1700 to 1708. A full export is about half its old size, so it is quicker to paste into the Ledger or into an AI. The data in the export is the same. The Adventurer's Ledger reads format 3 already, and exports from older versions still import.

## Adventurer's Ledger (Pandora Lunar)

- **Share codes.** Settings has a Share frame. It makes a short code, for example `K7Q2-M9XP`, for one character. Anyone with the code can open a read-only view of that character's progress. A code expires 48 hours after the last share, unless you tick "Keep this code permanently".
- **Backup with a share code.** Each share also stores that character's ticks, notes and display settings as a backup. Your browser encrypts the backup before it goes up, and only your owner key or one of your one-time recovery codes can open it. Use the owner key or a recovery code to restore the character in another browser. Keep them safe: if you lose both, make a new share with a new code.
- **Permanent codes update by themselves.** After you save a change, a permanent code uploads it again about a minute later, at most once every 15 minutes, while a Ledger page is open. The Share frame shows when the next automatic update goes up. Timed codes update only when you share again.
- **Format 3 imports.** The Ledger imports exports in the new, smaller format, and exports in the earlier formats.
- **Challenge Log tab.** The completion percentage updates on each + or − click, and the categories are in the same order as in the game.
