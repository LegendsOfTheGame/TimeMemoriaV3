## Tales of Milestones

- **Read achievement counts.** This button replaces "Read hunt counts" on the Progression tab, in both windows. It asks the game for 19 counts, one at a time (about 12 seconds): gathered collectables, crafted collectables, duties, and the 16 A and S rank hunt groups. You do not have to open the Achievements window first. It runs only when you press it.
- **Read counts, copy everything.** A new button. It reads the same 19 counts, then copies the full export when the read ends. This button and "Read achievement counts" send the only requests that the plugin sends to the game server.
- **Age of the counts.** The plugin shows when you last read the counts: beside the button in the classic window, and in the button's tooltip in the native window. "Copy for Adventurer's Ledger", "Copy everything", `/tm ledger` and `/tm full` also say it, for example "Achievement counts: 19 of 19, 3d ago."
- **Copy collections button removed.** "Copy everything" includes the collections. The command `/tm collections` stays.
- **Gear rewards at the turn-in.** When a reward option is gear, the quest turn-in window shows the eye beside "Reward". Click it to open `/tm food`, which shows how each option changes the bonuses that your current class uses. The option with the largest total gain is marked "Most improved".
- **Smaller hunt groups in the export.** The export no longer repeats each hunt group's name. The Adventurer's Ledger uses the id.
- **Fix: old collectable and duty counts.** A newer reading of an earlier tier could be ignored in favour of an older reading of a later tier, so a count could stay too low. The higher count now stays, whatever tier it came from.
- **Fix: reading times.** After a plugin reload, the last achievement read is no longer given a new time.
- **Fix: long food names.** In `/tm food`, a long name no longer covers the text on its right.

## Adventurer's Ledger (Pandora Lunar)

- **Relic grids.** The relic grids show each row in its tier colour, as the stage bar does. The Cosmic and Eureka grids count every stage (220 and 240).
- **Fix: relic cards.** A relic card that has a starting quest no longer says "no starting quest".
- **Fix: job tables.** The "not levelled" note counts only the jobs in its own table and shows only in that table's frame.
